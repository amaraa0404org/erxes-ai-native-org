Land the `erxes-api-shared/src/ai/` shared module — the cross-cutting foundation EVERY later phase depends on. This plan ships the full TypeScript surface (shim, encryption, redaction, tokens, providers/base, types) with zero real provider/agent/budget logic, plus the preconstruct/package.json plumbing that lets consumers `import from 'erxes-api-shared/ai'`. Purpose: Every later phase (1.2 provider CRUD, 1.3 LLM API, 1.4 settings UI, 2.x agents/RAG, 3.x automations) imports from this module. If it doesn't compile cleanly or doesn't ship the right type surface, nothing else can be built. The shim specifically enables XCUT-02 — disabling the `ai` plugin must not break `sales_api` or `frontline_api` consumers.
