# Phase 1.1 Plan 01: Shared Module Foundation Summary

One-liner: Lands the `erxes-api-shared/src/ai/` subpath — a typed graceful-disable shim (`createAIClient` + `AINotEnabledError`), AES-256-GCM per-subdomain encryption with versioned envelope, 5-pattern provider-key redaction, lazy-tokenizer cost tables, and provider interface stubs — the cross-cutting foundation every later AI Kernel phase imports from.

## What Was Built

**Public surface (`erxes-api-shared/ai`):**

- `createAIClient(subdomain)` — synchronous JS Proxy returning the full typed `trpc.ai.*` surface (`llm/rag/agent/tools/prompt/audit`). At every leaf method call, the proxy awaits `isEnabled('ai')` (60s TTL cache per subdomain) from `service-discovery.ts`. Throws `AINotEnabledError` if `ai` is not in `ENABLED_PLUGINS`; in Phase 1.1 it still throws with a `"Phase 1.2 wires the first real route"` addendum when enabled, because no real RPC routes ship yet.
- `AINotEnabledError` — `extends Error`, `name: 'AINotEnabledError'`, exact message `"AI plugin not enabled. Add 'ai' to ENABLED_PLUGINS and restart the gateway. Docs: https://erxes.io/docs/ai-plugin-setup"`. Docs link is the planned placeholder that Phase 3.2 backfills.
- `encryptSecret(plaintext, subdomain)` / `decryptSecret(ciphertext, subdomain)` — AES-256-GCM, 12-byte IV, 16-byte auth tag, `scryptSync(ERXES_SECRET, subdomain, 32)` key derivation. Envelope is base64-encoded JSON `{ version: 1, iv, ciphertext, authTag }` per PITFALLS §P14 Policy A.
- `redactKey(input)` — combined-alternation regex covering OpenAI `sk-`, Anthropic `sk-ant-` (matched before generic `sk-`), Groq `gsk_`, Google `AIza...`, Azure 32-hex. Replaces matches with `***REDACTED***`.
- `redactPii(text)` / `rehydratePii(text, map)` — public surface only in Phase 1.1; bodies are no-op wrappers until Phase 2.2 wires the per-agent opt-in via `redact-pii-light`. The wrapper degrades to no-op if the package fails to load.
- `COST_TABLE` — seeded with `openai:gpt-4o`, `openai:gpt-4o-mini`, `openai:text-embedding-3-small`, `anthropic:claude-3-5-sonnet-latest`, `google:gemini-1.5-pro` per STACK.md prices on 2026-05-21.
- `DRIFT_MULTIPLIER` — per PITFALLS §P7: openai/azure 1.0, anthropic 1.15, google/ollama 1.1, custom 1.2.
- `getTiktokenModule()` — lazy loader gated by `NODE_ENV !== 'test'` so jest doesn't pay the WASM cold-start; returns `null` in tests.
- `ILLMProvider` — interface only. Concrete adapters land in Phase 1.2.
- `PROVIDER_REGISTRY: Partial<Record<ProviderKind, () => ILLMProvider>>` — empty `{}` for Phase 1.2 to populate.
- Types: `ChatMessage`, `ToolDef`, `AiToolDef`, `Usage`, `ProviderError`, `ProviderKind`, plus full Zod schemas (`chatMessageSchema`, `toolDefSchema`, `usageSchema`, `aiToolDefSchema`, `chatRequestSchema`, `chatResponseSchema`, `embedRequestSchema`, `embedResponseSchema`, `modelInfoSchema`) — every object schema uses `.strict()`.

**Build / packaging:**

- `backend/erxes-api-shared/package.json` gains 4 exact-pinned deps and `"./ai/index.ts"` in `preconstruct.entrypoints`. `"ai"` added to `files`.
- `backend/erxes-api-shared/ai/package.json` (new): preconstruct convention `{main, module, types}` pointing at `dist/erxes-api-shared-ai.{cjs.js,esm.js,cjs.d.ts}`.
- `backend/erxes-api-shared/project.json`: declares `{projectRoot}/ai/package.json` and `{projectRoot}/ai/dist` as Nx build outputs (matches the existing utils/core-types/core-modules convention).
- `backend/erxes-api-shared/jest.config.ts` (new): ts-jest preset, `testEnvironment: 'node'`, `collectCoverageFrom: ['src/ai/**/*.ts', ...]`.

**Tests (4 suites, 34 tests):**

- `shim.test.ts` (5 tests): sync factory returns object, AINotEnabledError thrown when isEnabled=false (exact message match), AINotEnabledError thrown when isEnabled=true with `"not yet implemented"` + `"Phase 1.2"` addendum (distinguishes the two code paths), 60s TTL cache (3 method calls → 1 `isEnabled` call), AINotEnabledError instanceof Error + name + optional addendum.
