## Decisions Made

- **schemaWrapper not used.** Sales_api wraps schemas in `schemaWrapper` which auto-injects ES typings and helpers tailored to sales rows; the AI collections don't need those. Each AI schema declares `_id: mongooseStringRandomId` directly.
- **Azure config is plaintext, not encrypted.** `config.deploymentName` and `config.apiVersion` are non-secret operational metadata. Only the API key itself flows through `encryptSecret(...)` (Plan 05 owns that).
- **Connection-resolvers wiring moved into Task 2's commit** instead of Task 3 as the plan literally suggested. Reason: model-class static-method bodies reference `models.AiProviders` etc., so `tsc --noEmit` on the model files alone (Task 2's verify) cannot pass until `IModels` declares those members. This is a Rule 3 auto-fix (blocking type-contract dependency). Task 3 then ships only the smoke test, which is what the plan ultimately verifies.
- **`pnpm exec tsc` requires `pnpm install` first.** Clean worktree had no `node_modules`. Ran `pnpm install --prefer-offline` once at the start; subsequent verify cycles reused that install. This produced an unrelated `pnpm-lock.yaml` reduction (300 lines removed — stale dist-mirror entries) which is **NOT committed** (out of scope).

## Final `IModels` Shape (verbatim)

```typescript
export interface IModels {
  AiProviders: IProviderModel;
  AiModels: IModelModel;
  AiBudgets: IBudgetModel;
  AiProviderTestAudit: IProviderTestAuditModel;
}
```

Where:
- `IProviderModel extends Model<IProviderDocument>` with `getProvider/createProvider/updateProvider/removeProvider`
- `IModelModel extends Model<IModelDocument>` with CRUD + `listForProvider`
- `IBudgetModel extends Model<IBudgetDocument>` with `getBudget/setBudget/listBudgets/removeBudget`
- `IProviderTestAuditModel extends Model<IProviderTestAuditDocument>` with `recordAttempt/countRecent`
